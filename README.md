# OldWinOnLinux
This is a series of scripts to automatically install aerothemeplasma or vistathemeplasma on linux, which are themes for kde plasma that makes it look like Window 7 / Vista<br>
This is the best way to larp windows 7 while actually just using linux (installing linux is easier than installing windows 7 or vista on modern hardware trust me i tried)
<br>
<h2>How to install it</h2>
To install aerothemeplasma (theme that looks like windows 7) on arch, use this command:
./windows7de.sh -a <br>
To install vistathemeplasma (theme that looks like windows vista) on arch use this command:
./windowsVde.sh -a <br><br><br>

This is the same for openSUSE, Fedora and Debian, but instead of the flag -a use these:<br><br>
For openSUSE: ./windows(X)de.sh -s <br>
For Fedora: ./windows(X)de.sh -f <br>
For Debian: ./windows(X)de.sh -d <br>
